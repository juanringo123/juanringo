# Juan Music Portfolio

A modern personal music portfolio for Juan Marcos, built with HTML, Tailwind CSS, and vanilla JavaScript.

## Run

Open `index.html` directly in a browser, or run a local server from this folder:

```bash
python -m http.server 5500
```

Then visit `http://localhost:5500`.

## Included

- Responsive fixed navbar with mobile menu
- Fullscreen hero with generated stage visual
- About section with generated profile image
- Featured music cards with working local audio placeholders
- YouTube embed section using placeholder ID `9SgTz7ifVwY`
- Journey timeline
- Music skill cards
- Responsive gallery with lightbox
- Contact and social links
- Scroll reveal animation through `IntersectionObserver`

## Replace Content

- Update artist text in `index.html`.
- Replace images in `images/` with real photos or covers.
- Replace audio files in `music/` and update the `<audio>` `src` values if using `.mp3`.
- Replace the YouTube ID `9SgTz7ifVwY` with your own video IDs.
- Update social links and email in the contact section.

The generated website assets were created for this project with the built-in image generation tool. The current audio files are short local placeholder tones so the player can be tested immediately.
